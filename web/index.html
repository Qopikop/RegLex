RegLex Compiler Workbench

Educational compiler workbench for supported subsets of C, Java, and Python

Examples

Each rule is NAME PRIORITY token|skip REGEX; the lower priority wins a tie. Custom rules give lexical analysis only: tokens and automata are shown, but parsing, intermediate code and execution are skipped, because the parser only understands the built-in C, Java and Python token sets.
