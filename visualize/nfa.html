Token rules and their NFAs

Rules

    How to read this

    1 · Regex. The token type written as a pattern. [a-z] is one character from a range, * means zero or more, + one or more, ? optional, | either side.

    2 · Postfix. The shunting-yard algorithm rewrites the pattern so each operator comes after what it applies to; · means "followed by". ab* becomes a b * ·, which a program can build with a simple stack.

    3 · NFA. Thompson's construction turns the postfix into a machine. Start at the orange state. A solid arrow reads the character on it. A dashed ε arrow is a free move that reads nothing, which is how *, + and | are built. Being in the green state means the text read so far matches.

    "Nondeterministic" means the machine can be in several states at once. Run a string below to watch that happen.
